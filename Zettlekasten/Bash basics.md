- `#!/bin/bash` - we put this at first line of the script to identify that this file should be executed using `bash`
- `bash -x script` - run script in debug mode
- `shellcheck script`  - check the script 
- Rules/best practices:
	- DO NOT add extensions to files; we already put the first line
	- Always use variable in brackets -> `${name}`
