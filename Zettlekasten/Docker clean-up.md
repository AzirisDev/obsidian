Clean-up commands:
- `docker stop webserver` - stop container
- `docker rm webserver` - remove container
- `docker rm -f webserver` - stop and remove container
- `docker container prune` - remove all stopped containers
- `docker rmi ngnix` - remove image
- `docker image prune` - remove unused images
- `docker system prune -a` - USE WITH CAUTION: Removes all stopped containers, unused networks, unused images
- `docker volume rm pgdata` - remove single volume
- `docker volume prune -a` - remove all volumes that are not in use
