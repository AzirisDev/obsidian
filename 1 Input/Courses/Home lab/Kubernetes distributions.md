Kubernetes is a set of binaries that runs on Linux distribution. We can setup Kubernetes cluster in several ways.

#### Kubeadm
You will see it in CKA. Hard-core stuff for learning deep, but hard to manage -> setup certificates, CNI management.

#### MicroK8S
Distribution developed by `Canonical`. Easy to install but has a way to work with, no room for experiments and f-ups. 

#### Talos Linux
Production-grade, secure and closed OS with Kubernetes in it. No way to connect except API. More advanced way.

#### K3S
Balance between ease and learning; Easy to install; Powered by Rancher, enterprise level of Kubernetes management;


In general, it does not really matter which distribution to choose cause we going to implement GitOps to make it portable.
