`K9S` is a tool to navigate across the k8s cluster.
It has very useful hot keys and vim bindings.
It gives cluster, context information, and many other.

- `0, 1, 2, ...` - change namespaces
- `Shift + A` - sort by age
- `Shift + S` - sort by status
- `/` - to search 
- `d` - describe
- `e` - edit, it will open vim
- `y` - open yaml file
- `s` - open shell
- `Shift + d` - delete
- `l` - logs
- `s` - toggle autoscroll during logs mode 
- `Ctrl + d` - go down page, `Ctrl + u` - go up page
- `Ctrl + k` - kill
- `Shift + f` - port forwarding
- `; + deploy/service/pvc/pv` - show deployments, services, etc
- `s` - scale deployments in deployment mode
